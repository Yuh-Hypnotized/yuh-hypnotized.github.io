Face Recognition PCA

Face recognition using PCA (Principal Component Analysis) eigenface method on the ORL face dataset, implemented in MATLAB. Computes eigenfaces via small-sample trick, projects training/test images into the PCA subspace, and classifies using nearest-neighbor. Achieves accuracy on the standard 40-person ORL benchmark with 8 train / 2 test split.
