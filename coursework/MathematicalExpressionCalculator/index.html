Mathematical Expression Calculator

A command-line mathematical expression evaluator implemented in C++. Parses and computes expressions with operator precedence (+, -, *, /, ^) and parentheses using dual-stack architecture (number stack + operator stack). Handles decimal numbers, right-associative exponentiation, and priority-based evaluation order with infix parsing.
