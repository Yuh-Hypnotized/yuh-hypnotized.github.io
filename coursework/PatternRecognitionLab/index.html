Pattern Recognition Lab

Pattern recognition course lab exercises implementing two classic algorithms in C++: K-Means clustering (unsupervised learning, dynamically groups 2D points into K clusters with iterative center refinement) and Perceptron (supervised binary linear classifier, iteratively adjusts weight vector on misclassified samples with fixed increment correction).
