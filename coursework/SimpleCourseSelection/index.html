Simple Course Selection

A student course selection management system built with Qt5 C++. Features include adding/deleting/searching students, managing course enrollments, student list & course list views with detailed information dialogs, and file-based data persistence via QTextStream. The UI is responsive with custom resize events and a semi-transparent background.
