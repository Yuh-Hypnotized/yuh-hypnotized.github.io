Face Recognition PCA

A

Face recognition using PCA eigenface method on the ORL face dataset (40 persons, 10 images each), implemented in MATLAB. Computes eigenfaces via the small-sample trick, projects training/test images into the PCA subspace, and classifies using nearest-neighbor with 100 components. Includes eigenface visualization, test sample recognition display, and accuracy reporting.

StackMATLAB
DomainComputer Vision · ML
DatasetORL (40 persons)
