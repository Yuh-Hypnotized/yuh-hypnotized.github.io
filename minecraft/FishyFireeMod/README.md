# FishyFireeMod
## Introduction of features
**Counter:** Counts Blocks and Arrows in your inventory and display the amount in a hud.  
  **/counter toggle** - Toggle on/off the counter hud.  
  **/counter settings** - Settings for the counter.  
  
**PlayerTracker:** Tracks rendered players and displays the distance & y-distance for the nearest player in each team, like a compass.  
  **/playertracker toggle** - Toggle on/off the playertracker hud.  
  **/playertracker settings** - Settings for the playertracker, including team color custom settings.  
  
*You can also set hotkeys to toggle the counter/playertracker in minecraft settings.*
