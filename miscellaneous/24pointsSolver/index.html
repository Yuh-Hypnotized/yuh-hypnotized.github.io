24-Point Solver

A C++ brute-force recursive solver for the classic 24-point math puzzle. Given 4 numbers (1–13), it enumerates all possible binary operation trees using +, -, *, / to find every expression that evaluates to 24. Outputs all valid solutions with parenthesized expressions showing the exact order of operations.
