Matrix Calculator

A comprehensive command-line C++ matrix calculator supporting 10 operations: transpose, row-minimalization (Gaussian elimination), addition, subtraction, multiplication, inversion, determinant, adjugate matrix, linear system solving (Cramer's rule + Gaussian elimination with free variables), and eigenvalue/eigenvector computation via sweep search. Features an interactive menu system with input validation and formatted output.
