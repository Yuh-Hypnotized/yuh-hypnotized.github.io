VideoRefiner

An AI-powered video frame interpolation tool built with Python & PySide6. Feed it a video at any source framerate and it outputs a higher framerate (e.g. 60→120fps) by inserting AI-generated intermediate frames only — original frames stay untouched. Powered by the RIFE optical-flow model (v4.26) with scene-change protection, an audio passthrough, a Chinese desktop GUI with batch queue, and a CLI entry for scripting.
