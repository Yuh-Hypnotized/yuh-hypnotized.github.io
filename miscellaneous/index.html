VideoRefiner

An AI-powered video frame interpolation tool built with Python & PySide6. Input any source framerate and output a higher one (60→120, 24→60, …) by inserting AI-generated intermediate frames only — original frames stay untouched. Powered by the RIFE optical-flow model (v4.26) with scene-change protection, audio passthrough, a Chinese desktop GUI with batch queue and side-by-side comparison playback, plus a CLI entry for scripting.

24-Point Solver

A brute-force recursive C++ solver for the classic 24-point math puzzle. Given 4 numbers (1–13), it enumerates all possible binary operation trees — trying every pair of numbers with +, -, *, / at each step — to find every valid expression that evaluates to 24. Outputs all solutions with fully parenthesized expressions showing the exact order of operations.

Matrix Calculator

Features an interactive menu system with formatted output.
