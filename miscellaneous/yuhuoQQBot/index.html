yuhuo QQ Bot

A multi-module Mirai Console QQ bot plugin suite built with Kotlin/Java. Features include: a 24-point math game, anti-recall message logging, interactive Gomoku (五子棋) with board rendering via Java2D, daily luck (人品), and a unified command dispatch system. Modular architecture with shared config loading via Gson.
